# database-query-optimization-postgresql
SQL scripts, datasets, and execution plan outputs for a PostgreSQL query optimisation study analysing execution strategies using EXPLAIN (ANALYZE, BUFFERS).

# Database Query Optimisation in PostgreSQL

This repository accompanies an academic project analysing query processing
and optimisation techniques using a transactional grocery sales database.
The study focuses on execution plan behaviour, aggregation strategies,
predicate formulation, and index utilisation in PostgreSQL.
